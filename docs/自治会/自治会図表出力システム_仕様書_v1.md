# 自治会図表出力システム 仕様書 v1

## 1. 目的
浜松市の **各地区の自治会世帯数** を、
- **棒グラフ（降順）**
- **円グラフ（構成比）**

の2枚セットで作成し、Illustrator で編集できる素材（SVG/EPS/PDF/PNG）として一括出力する。

本v1は、
- 既存システムの「出典表記・データ前処理の考え方」を維持
- テストシステムの「configによるデザイン調整・多形式書き出し・検証スクリプト」を踏襲
- 合意済みの追加要件（bar/pieサイズ分離、barの自治会数レンジ別プロフィール、pieラベル上位5、同名自治会の表示名ユニーク化、未知region_keyの対話UI）

を統合したもの。

## 3. 入力データ（CSV）仕様
### 3.1 既定の配置
```
<project_root>/data/自治会/<年>/自治会世帯数__<年>.csv
例: data/自治会/2025/自治会世帯数__2025.csv
```

### 3.2 必須列
|列名|型|意味|
|---|---|---|
|`region_key`|文字|地域キー（例: `kita` など）|
|`district`|文字|地区名（例: `三ヶ日地区`）|
|`jichikai`|文字|自治会名称|
|`households`|数値|世帯数|
|`corporate`|論理|法人格（TRUE/FALSE）|

### 3.3 任意列
|列名|型|意味|
|---|---|---|
|`asof`|文字|「令和7年4月1日現在」等の出典日付（単一値なら採用）|

> `region_key` が無い場合、v1は **停止**（既存システムの要件を維持）。

---

## 4. 処理フロー（機構）
全体の機構は **「CSV → 地域→地区ループ → 2図（bar/pie）生成 → 形式別に保存」** のまま。

1. CSV読み込み（無ければダミーデータ生成、警告表示）
2. `region_key + district` 単位で **同名自治会の表示名をユニーク化**
3. 地域→地区でループ
4. 地区ごとに
   - 自治会数 `n` を数える
   - barプロフィールを決める（後述）
   - bar/pie を生成（タイトルに `（計n自治会）` を反映）
   - 4形式で書き出し（barとpieは別サイズ）
5. 出力マニフェスト（CSV）・embedFontsログ・警告ログを作る

---

## 5. 同名自治会の表示名ユニーク化
### 5.1 目的
同一地区内で `jichikai` が同名の行があると、
- bar の y 軸ラベルが衝突
- pie の色割当/凡例/ラベルが衝突

して描画が破綻する。

### 5.2 仕様
同一地区内の同名自治会は **すべて** `（1）` から連番を付与。

例：
- `市場` が2つ → `市場（1）`, `市場（2）`

このユニーク化は **表示名だけ**（元データを改変しない）で、並び順は **入力出現順**。

### 5.3 法人格マークとの関係
法人格が無い自治会（`corporate == FALSE`）は、表示名の先頭にマークを付与。
- 既定: `×`
- 設定: `cfg$label$non_corp_mark`

例：
- `市場（1）` が非法人 → `×市場（1）`

---

## 6. 図表タイトル仕様（計○○自治会の自動反映）
地区内自治会数を `n` とすると、

- bar: `地区名（計n自治会）：自治会別 世帯数（降順）`
- pie: `地区名（計n自治会）：自治会別 世帯数構成比`

を必ず使用する。

---

## 7. 出典表記（既存システム準拠）
既存システムの文言を踏襲し、地域名の差し込みだけを調整。

既定のキャプション:

> 出典：浜松市自治連合会「<地域名>の地区別単位自治会」（<令和表記日付>）を基に作成

- `<地域名>` は `region_key` を対応表で日本語化したもの（例：`北地域`）
- `<令和表記日付>` は `asof` が単一値なら採用、無ければ空扱い

## 8. bar（棒グラフ）仕様
### 8.1 デザイン基準
デザインの基本はテストシステムを基準にし、調整ノブは `cfg` に集約。

### 8.2 自治会数レンジ別プロフィール（合意済み）
棒グラフは、地区内自治会数 `n` に応じてプロフィールを切り替える。

|条件|bar_width|書き出しサイズ（インチ）|文字サイズ|
|---|---:|---:|---|
|`6 ≤ n ≤ 10`|0.5|w=7, h=3|既定|
|`11 ≤ n ≤ 15`|0.5|w=7, h=5|既定|
|`n ≥ 50`|0.5|w=7, h=7|`name_size=4.5`, `value_size=1.5`, `rank_size=1.5`|
|その他|既定|w=7, h=7|既定|

プロフィール定義は `lib/自治会/自治会_デザイン設定_v1.R` の `cfg$bar_profiles` にある。

---

## 9. pie（円グラフ）仕様
### 9.1 基本
pie は **常に** テスト設定（7×7）。

### 9.2 ラベル（上位5のみ）
ラベル（自治会名＋世帯数）は **世帯数の降順で上位5自治会のみ**表示。
- スライス自体は全自治会分を表示（色も全スライスに割当）
- ラベルが多すぎて潰れる問題を根本的に回避する

`cfg$pie$label_top_n = 5` で固定。

---

## 10. 出力仕様（4形式＋フォルダ構造）
### 10.1 出力ルート
```
<project_root>/figures/自治会/<年>/<run_id>/
```

`run_id` はスクリプト実行時刻から生成（例：`jichikai_20260102_061530`）。

### 10.2 形式別フォルダ
出力は形式ごとに分岐。

- `pdf/`
- `png/`
- `svg/`
- `eps/`

### 10.3 地域フォルダ
形式フォルダの下に、地域名（日本語）を作る。
例：`北地域`, `天竜地域`, `浜北地域` ...

### 10.4 bar / pie の分岐
地域フォルダの下は
- `bar/`
- `pie/`

### 10.5 bar はプロフィール（サイズ仕様）ごとに分岐
bar は **プロフィール別フォルダ**に入る。

例（概念）：
```
pdf/北地域/bar/default__w7h7__bw0.7/
pdf/北地域/bar/n06-10__w7h3__bw0.5/
pdf/北地域/bar/n11-15__w7h5__bw0.5/
pdf/北地域/bar/n50plus__w7h7__bw0.5__smalltext/
```

pie は固定フォルダ（常に同条件）
```
pdf/北地域/pie/fixed__w7h7__top5/
```

### 10.6 ファイル名
地区名をベースにしたファイル名。

- bar: `自治会世帯数__<地区名>_bar.<ext>`
- pie: `自治会世帯数__<地区名>_pie.<ext>`

`<地区名>` はファイル名安全化（記号置換）を行う。

## 11. embedFonts（PDF/EPS）
### 11.1 方針
PDF/EPS に対して **必ず embedFonts() を試行**する。

- 成功：フォントが埋め込まれ、他環境での崩れが減る
- 失敗：**止めずに続行**。失敗理由をログに記録

### 11.2 Ghostscript が無い場合
Windowsで Ghostscript 未導入、または PATH 未設定だと embedFonts が失敗しやすい。
ただし本v1は **出力自体は継続**し、以下に記録する。

---

## 12. ログ
`<run_root>/logs/` に出力。

- `export_manifest.csv`  … 作成したファイル一覧（format, region, profile, path 等）
- `embedFonts_log.csv`   … embedFonts の成否とエラーメッセージ
- `warnings.txt`         … 警告・エラー（地区単位で続行した場合も記録）
- `unknown_region_keys.txt` … 未定義 region_key を「続行」した場合の記録
- `ghostscript_detect.txt`  … Rから見える Ghostscript 検出結果

---

## 13. 未定義 region_key の扱い
### 13.1 基本方針
対応表 `cfg$region$map` に無い `region_key` が来たら、原則 **停止**。

### 13.2 対話実行（RStudio等）
`interactive()` の場合のみメニューを出し、
- 続行（フォルダ名 `未定義地域_<region_key>`）
- 停止

を選べる。

### 13.3 非対話実行
非対話（バッチ等）は **configで許可しない限り停止**。

- 続行を許可： `cfg$region$allow_unknown_noninteractive = TRUE`

続行した場合は `unknown_region_keys.txt` に必ず記録される。

## 15. 依存パッケージ
最低限：
- tidyverse系: `readr`, `dplyr`, `ggplot2`, `forcats`, `scales`

## 16. Windows パス長について（注意）
出力パスが

`形式/地域/bar仕様/地区名/ファイル名`

と深くなるため、Windowsの環境によってはパス長制限に当たる可能性がある。

対策の方向性（必要になったら）：
- プロジェクトルートを浅い場所へ置く（例：`C:\work\proj`）
- Windows側の長いパス許可（ポリシー/レジストリ）

※ 本v1は「意味が分かるフォルダ名を優先」し、フォルダ名短縮は行わない。

## 18. 既知の弱点・リスク（v1時点）
1. **Ghostscript未設定**だと embedFonts が失敗しうる（出力は継続、ログで把握）
2. **地区名・自治会名に特殊文字**が多い場合、ファイル名安全化で置換される（中身は問題ない）
3. **非常に多い自治会（50+）**は「文字サイズダウン」で対応済みだが、極端に長い名称が多いと限界はある
